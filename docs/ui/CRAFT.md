## 0. 公理

**网页的默认语法是「文档」——内容一次性渲染好，等你读。
游戏的语法是「舞台」——事件在时间里、在场地上，被上演。**

质感不主要来自画面华丽度，来自七层，按依赖顺序：

| 层 | 一句话 | 章 |
|---|---|---|
| 地基 | 把浏览器藏干净 | §1 |
| 舞台 | 有场地：地面、远近、遮挡、镜头 | §2 |
| 时间 | 状态变化被导演成事件 | §3 |
| 身体 | 输入被三通道回应、会抵抗、能跟手 | §4 |
| 物质 | 物件恒存、数字物化、idle 呼吸 | §5 |
| 声音 | 一半的质感 | §6 |
| 地板 | 稳帧率，掉帧毁一切 | §7 |

验收四问见 §8，破功快查见附录 A。

## 1. 地基：把浏览器藏干净

**1.1 默认行为零漏出。** 文字被选中、tap 高亮、橡皮筋滚动、双击缩放、长按弹菜单、拖拽幽灵图、原生 focus 外观——任何一样漏出，玩家立刻回到网页。统一 reset：

```css
html,body{height:100dvh;overflow:hidden;overscroll-behavior:none}
body{user-select:none;-webkit-user-select:none;-webkit-tap-highlight-color:transparent;touch-action:manipulation}
img,svg{-webkit-user-drag:none}
```

**1.2 文档不滚，容器可滚。** 页面本身永不滚动；需要滚动的区域（如流式历史）在容器内滚——隐藏滚动条，保留惯性。

**1.3 资源不闪。** 字体 preload（FOUT 一闪即出戏）；图标与骰面内联 SVG；进局后零网络请求、零解码卡顿。

**1.4 正式版套 PWA standalone。** 去掉地址栏是最便宜的全屏游戏错觉。样机阶段不做。

**1.5 无障碍不是牺牲品。** focus 外观自定义而非删除；`prefers-reduced-motion` 下屏震、视差、粒子降档，但节拍与信息不减。

## 2. 舞台：场景与 HUD

> 空间感不是「加 3D」，是画面里存在一个**有地面、有远近、有遮挡、被镜头看着的场地**。

**2.1 两层制（本章总纲）。** 每屏先分两层：**场景**——活在世界里的东西（桌面、骰、盅、池、引信）；**HUD**——贴在玻璃上的东西（按钮、读数、验封文本）。空间线索只加给场景层，HUD 保持平面；分不清的默认 HUD。

**2.2 有地面。** 场景层要有受光渐变的地（近亮远暗／近暖远冷）＋四角晕影（＝围合）。一条含蓄的「远边」出现，房间就出现。

**2.3 遮挡优先。** 布局允许压叠：骰压桌纹、手牌压桌沿、池压桌心。遮挡是最强的静态深度线索；flex/grid 式互相避让的平铺是海报构图。

**2.4 接触影。** 表达「东西在场景里」用物体正下方小而深的影（把它钉在面上）；大而虚的浮影只留给真正悬浮的 HUD。

**2.5 远近梯度。** 它＝远：小一号、偏冷、低对比（可 0.5px blur）。你＝近：大一号、偏暖、锐、允许被下画框裁切——近处物被画框切掉一截，就是「在镜头跟前」。

**2.6 视差。** ≥2 层，pointer 或陀螺仪驱动；参考幅度：背景 2px／中景 5px／前景 8px。幅度极小也读得出纵深。

**2.7 镜头只属于场景。** 紧张时缓推（约 scale(1.02)），开牌拉回；HUD 永不随镜头动——这个分离本身就在宣告「那边是个世界」。

**2.8 对称入世界，不对称留给视点。** 公平要求的对称做进**世界空间**（对坐、等距、同资源、同器物），不做成屏幕上下两块对称贴片；视点造成的近大远小不损公平——那只是「你坐在自己的位置上看」。I·圆桌已示范。

## 3. 时间：事件被上演

**3.1 更新与事件分流。** 改状态前先问：这是**刷新**（无戏剧权重：余额微调、次要读数）还是**事件**（报价、宣言、开牌、判定、掉骰）？事件一律走编排序列：**预备 → 冲击 → 余韵**。

**3.2 预备拍。** 大事件前静 150–300ms。蓄力比爆发更造紧张，开牌前那一拍沉默是仪式的一半。

**3.3 冲击三件套，分级使用。** 白闪 1–2 帧／屏震（幅度随事件分级）／**hit-stop**（全场冻结 60–100ms 再恢复，含粒子层）。hit-stop 只留给全局最重事件（开牌判定），一局至多一次——**通胀即贬值**；屏震同理分级。

**3.4 逐项展开。** 集合信息（逐颗骰、清点计数）逐个亮，间隔 80–120ms，每项伴 tick。

**3.5 缓动一律非线性。** 入场过冲（`cubic-bezier(.2,1.4,.4,1)` 系）、出场 ease-in、位移弹簧；`linear` 与默认 `ease` 不许出现在玩家可感动画。

**3.6 可中断（[D§3] 的工艺实现）。** 任何仪式满足其一：短于 400ms；或可被输入打断/加速；或与输入并行（台词流式打字即此类）。输入层永不因动画锁死；skip 不是补丁，是设计。

**3.7 余韵不锁人。** 大事件后视觉余韵（粒子落、余晖）可持续 300ms 以上，但 UI 在冲击结束即恢复可操作——余韵是画面的事，不是输入的事。

**3.8 防录像感。** 同一动画每次带 ±10% 时长/幅度抖动；粒子、骰落同理（音效见 §6.3）。逐帧完全一致的重复是录像，不是世界。

## 4. 身体：输入的手感

**4.1 三通道 ≤100ms。** 每次有效触摸给三通道回应：视觉（`:active` 吃进去，scale .95–.97）、听觉（<80ms 短音）、触觉（vibrate 10–30ms；仅 Android 生效，iOS 自动缺省）。

**4.2 抵抗而非禁用。** 不可用操作不灰掉了事：按下去要顶回来（横向 shake、闷音、短震）＋就地一行原因。灰按钮是表格语法，会抵抗的按钮才在世界里。

**4.3 跟手。** 拖拽直接映射（手指到哪物到哪），松手弹簧入位/归位；长按蓄力要有可见的力积累，拖离可取消。样机现以点按为主——蓄力开牌、拖注入池是手感上最大的未开发杠杆。

**4.4 空点也有回应。** 点在空处给最低限度的微光/涟漪。世界感觉得到你，才是世界。

## 5. 物质：物件与数字

**5.1 物件恒存。** 东西有来处与去处：骰从盅出、回手牌；注从你的堆飞入池；池滑向赢家；新一局是**收拾桌子**，不是重渲染。凭空出现/消失的物件是网页。

**5.2 数字物化。** 数值不做瞬时替换：滚动、逐跳、飞块；变化量要在空间里走完「从哪来、到哪去」的路。赌注的重量一半在这。

**5.3 idle 呼吸。** 任何停留态保持 1–2 个低频运动（光呼吸、presence 灯、引信抖）；超过 2 个是噪音。静止帧＝网页。

**5.4 材质同源。** 全部颜色、光、质地服从同一光源与同一世界设定；系统默认排印、默认蓝、默认控件视为异物。

**5.5 边框克制。** 1px 通框是图表语法；场景层物体靠光影与质地分离，不靠描边。HUD 可用细框，但同屏框族 ≤2 种。

## 6. 声音：一半的质感

**6.1 首手势解锁。** AudioContext 在第一次手势解锁；解锁前视觉不等声音。

**6.2 短音配事件，重音留判定。** 每个 UI 事件配 <80ms 短音；开牌/判定独享 80–150Hz 低频重音——身体感来自低频。

**6.3 变调防录像。** 每次播放 detune/playbackRate 随机 ±5%。

**6.4 语义音高。** 阶梯越深音越紧、越高；开牌是全场最低音。目标：闭眼听一局，能听出局势起伏（§8.3）。

**6.5 混音三层。** 氛围底噪 < UI tick < 判定重音，同层不抢；重音前压底噪一拍——留白也是混音。

**6.6 [D§5.5] 同样约束声音。** 金币倾泻、老虎机卷轴、轮盘珠声属于赌场皮肤，禁用；重物、机械、纸墨、火星按各世界自取。

## 7. 地板：帧率

**7.1 60fps 是质感的地板。** 掉帧比丑十倍更出戏——jank 一下，舞台塌回网页。

**7.2 合成器动画。** DOM 动画只碰 transform/opacity；粒子与光场走独立 canvas/WebGL 层；禁 layout 读写交错。

**7.3 真机验收与降级次序。** 中端安卓＋低电量模式跑最重场景（开牌全特效）稳 60fps；不稳则按次序降级：景深 → 视差层数 → 粒子量 → 光场分辨率。**三拍节奏与冲击帧永不砍**——节奏是骨，特效是肉。

**7.4 预载一切。** 字体、音频 buffer、首屏纹理先行；对局中零请求零卡顿（同 §1.3）。

## 8. 验收四问

交付（样机定稿、生产 UI 里程碑）前过一遍：

1. **录屏问答**：录 10 秒给外人看——「网页还是游戏？」分不出才过。
2. **眯眼测试**：截屏高斯模糊——读出「一个地方」（近暗远明梯度、有物压物）还是「一张排版」（栏目感）？
3. **闭听测试**：只听声音走一局，能否听出局势起伏与胜负时刻？
4. **真机测试**：中端机低电量、最重场景，稳 60fps。

外加合规两查：[D§3] 任何时刻输入不被动画/台词锁死、「AI 生成」标识常驻；[D§5.5] 词表、视觉、**声音**（§6.6）各过一遍赌场皮肤自查。
