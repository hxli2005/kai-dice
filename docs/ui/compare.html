三套没有一套全赢，而且输赢的位置正好错开：B 最能兑现 H1（被读上头），C 最能兑现 H2（台词与切片是核心传播物），A 在气质与手机适配上最省事。DESIGN §7.1 的两个假设分别指向两个不同的方向，这就是这次选型真正的难处——不是哪个好看。

可缝的地方（不是折中，是结构上真能嫁接的一处）：A 的桌面侧板本来就是空的容器，把左侧那条打印纸带换成 B 的 belief 双通道流，A 就同时拿到了机器气质与推理常驻；手机版仍保持 A 的单柱，推理退回复盘室。代价是桌面与手机的信息量差距被拉大——要不要接受这个差距，是选 A 之前该先回答的问题。

C 是唯一一个"选了就得配美术资源"的方向（描边斜体展示字＋KO 演出）。按 §6.5 的 100KB webfont 预算，它是三者里唯一会真的把预算吃满的。
