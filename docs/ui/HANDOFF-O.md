## 1. 定死的（照抄，不许走样）

**世界观铁律**：光的世界单色磷光，物的世界才有颜色；**红色只存在于物理层**（LED、红键帽）与判定语义。

**结构（公平五条的硬件化）**：
- 三只**同尺寸**显像管垂直排列：绿磷管=它 / 白磷管=裁判（居中）/ 琥珀磷管=你。对称即公平，座位差异只进铭牌文字。
- 机壳层：LED 灯条=阶梯（前5琥珀、后5红=深水，烧到哪颗哪颗上方溅火星）、判定红LED、蚀刻电路走线（数据包在管间爬行）、实体键区（报=白键、开=红键帽、盲/斋/抬/算/戳）。
- 它的台词只住绿管（终端行，`> ` 前缀，**AI生成标识常驻** [D§3]）；你的算是琥珀管里的虚线私注「仅你可见」。

**显像管质感配方（每管）**：枕形玻璃口（四边外鼓 bow≈2.5、角R≈13）→ 光栅内缩 4px 留未点亮暗带 → 余辉缓冲（保留率 0.70/16.7ms，**按 1−0.7^FR 时间归一**）→ 四角径向衰减 → 框唇顶部内影 → 弯缘折射高光（上亮下无）→ 每管独立相位扫描线 → 偶发单管闪烁。外层整机 WebGL 玻璃：微鼓 .030、法兰内缩 4.5%、屏光溢框、随视差游走的眩光带、highp 条件精度、上下文丢失自愈+null 降级。

**「它」= 示波心跳**（绿管）：说话随打字起声纹、思考变密提速、**开牌拉平（停搏）、下一局复苏**。这是"它"的唯一化身，不加任何具象形体。

**判定语言**：白管反白视频条「成 立」（微闪）＋机壳判定LED亮红＋sDrop 低锤（118Hz 起、**判定专属**）。无印章、无任何非电子隐喻。

**节拍表**（±10% 抖动 [§3.8]，全程可加速：seq/think 点屏=3.2×）：
开机 650ms 通电白线 → 三管递次暖机（白点→横线→满栅，各配升调）→ LED 自检跑马；
追注：预备 320ms → 双方各一小串注沿走线入白管，**每枚到账**池+1（弹跳1.55×+进位声递升+管内12粒火花+微震）→ LED 进档重击；
开牌：预备拍 240ms → 白闪+glitch+震屏+sDrop+下扫 → 心跳停搏 → 加密块逐块解密 160ms/块（绿磷线框骰）→ 点清 150ms/枚（双管命中闪+爬梯音、白管计数攀升）→ 反白条+判定LED+hit-stop85ms（一局唯一一次）→ 结算筹码流（池被逐枚搬走、滚降可见、落管炸花）→ 赢家管内 ±N 大浮字+中锤+震 → 验讫行 → 下一局键升起。

**声音**：全 8-bit 合成、每次 ±5% 变调、挂起门控（AudioContext 非 running 不发声）、低锤只属判定、爬梯音高随阶梯深度升、底噪<tick<锤。

## 2. 样机造假的（施工须换真）

- 对局数据写死（HAND/OPP/4个5/池18/53%），只有 A（你开）B（报满→它开）两条演出线。
- 盲/斋/抬/算/戳五键**未接线**（点按只给抵抗反馈）；掐/词条一概没有。
- 台词三句写死；生产必须**流式**接台词管线（打字机驱动心跳声纹的钩子已留：`WAVE.voice`）。
- 无大厅/报告卡/复盘室/三人桌/好友房；无 reduced-motion 降档 [§1.5]；无 PWA [§1.4]；真机 60fps 验收未做 [§7.3]。
- 「它算过 N 次」/骰数等为演出值，须接引擎事实。

## 3. 施工要点

- **接口**：一切事实走 `src/engine.js` 的 observe()/act()，样机 S/V 状态改为引擎事件驱动；渲染层可整体移植（时钟/补间(带同键去重)/at 调度/FR 帧率归一/hit-stop/代际门控 GEN/管内粒子 burstT/余辉缓冲/CRT 玻璃着色器）。
- **台词**：流式 token → 终端行逐字 + WAVE.voice 脉冲；永不阻塞输入 [D§3]。
- **多局**：换局=收拾桌子非重渲染 [§5.5]——块反向翻面重上封、池滚回、心跳复苏已示范。
- **合规自查**：词表/视觉/声音过 [D§5.5]（无赌场器物、无金币声）；「AI 生成」常驻；样本数等口径见 DESIGN。
- **验收**：CRAFT §8 四问（录屏问答/眯眼/闭听/真机60fps）＋附录A 破功快查逐条过。

## 4. 已了结的债

21+18 两轮 agent 对抗审查共 26 条坐实**全部修毕**（fp16 精度、上下文丢失、重入、120Hz 归一、音频积压、粒子入管等——细节见 SYNC 2026-08-12 各条）。证伪未修而接受的：boot 跳过时 power 补间的死写入（不可见）、LED 爆点含 #ff8a5c（机壳物理层，合法）。
