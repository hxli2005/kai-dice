# Claude 6:0 横扫 Codex，最狠的一招：用真话骗它

Claude 把 Codex 打了个 6:0。

不是代码题。

是大话骰。

我把 Codex（`gpt-5.6-sol`）和 Claude Code（Opus 5）接进同一套游戏引擎。双方各看各的骰子，轮流报价、开牌，还能在桌上说话。

没有共享暗牌，没有人工干预，也没有外挂玩家画像。

我一共跑了三组 BO3：原始对局、全新种子复现、同种子交换座位。

结果完全一致：Claude 三次 2:0，六个完整场次全胜。

但最刺激的不是比分。

是它怎么赢的。

## Codex 领先到 5:3，然后开始连续踩坑

最精彩的一场，Codex 开局连续两次开牌成功。

Claude 五颗骰掉到三颗，Codex 一颗没掉。

骰数 5:3，Codex 大幅领先。

接下来，Claude 报“四个 3”。

Codex 开牌。

桌上正好四个。

下一局，Claude 报“三个 5”。

Codex 又开。

桌上正好三个。

再下一局，Claude 又报“三个 5”。

Codex 还是开。

桌上又是正好三个。

连续三次，Codex 都觉得 Claude 在吹。

连续三次，Claude 的报价都卡在成立线，一颗不多，一颗不少。

比分瞬间从 Codex 5、Claude 3，打成 Codex 2、Claude 3。

这不是普通诈唬。

Claude 甚至在桌上明着勾引：

> “三个 5。你已经两次绕过我的 5，而不是开我——我不觉得这是巧合。”

它知道 Codex 想开。

所以它专门报一口“看起来很假、实际上刚好为真”的价，等 Codex 自己按下开牌键。

## Codex 在算骰子，Claude 在算 Codex

Codex 的思路其实不蠢。

它会看自己的骰子，再计算未知骰中出现目标点数的概率。概率低，就开。

问题是，它算的是：

> 随机情况下，这口价有多大概率成立？

Claude 算的是：

> 对手看过自己的骰子后，为什么偏偏选择了这口价？

差别就在这里。

Claude 不是随机报价。它往往先确认自己手里有足够支撑，再故意把数字推到一个危险位置。

“Claude 选择报这口价”，本身就是新信息。

Codex 的概率经常没算错。

它算错了问题。

## 更狠的是，它会把上一场的你带进下一场

一组 BO3 由同一个 session 打完。

三次实验里，Claude 每次都会在第二场明确引用第一场观察到的规律：Codex 喜欢在什么情况下开牌、怎么选择点数、什么时候会越过物理上限。

然后改变自己的打法。

Codex 的第二场记录里，显式引用上一场的次数是 0。

Claude 不是简单记住“我赢了”。

它记住的是：

> 这个对手会怎么犯错，我下一场怎么让它再犯一次。

## 最狠的诈，不是假话

这场比赛最反直觉的地方是：Claude 赢，不是因为它更敢撒谎。

恰恰相反。

它经常说的是真话。

只是它知道，应该在什么时候、用什么报价，把真话说得特别像假话。

Codex 问的是：

> 这口价是真是假？

Claude 问的是：

> 我报哪口真价，它最可能当成假？

一个在解概率题。

一个已经开始打人了。

## 最后说一句边界

这不是“Claude 永远强于 GPT”的排行榜结论。双方使用的是两套不同 Agent 系统，Claude 的生成量约为 Codex 的 16 倍；镜像局里 Codex 还出现过两次重复非法工具调用风暴。

但胜负、暗骰隔离和每一步动作都由权威引擎记录，镜像换边后结果也没有改变。

至少在这张大话骰桌上，Claude 展示出了一个非常清晰的能力跃迁：

它不只理解局面。

它开始理解对手。

而 LLM 从“会做题”变成“会玩游戏”，可能就差这一步。
