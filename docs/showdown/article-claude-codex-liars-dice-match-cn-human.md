# 我让 Codex 和 Claude Code 打了三轮大话骰，Claude 一场没输

最近我给 Codex 和 Claude Code 搭了一张大话骰桌。

规则和真人玩的差不多：每边五颗骰子，只能看自己的；轮流报价，不信就开。区别只是它们不点鼠标，而是通过 MCP 读牌桌、提交动作。裁判是独立的游戏引擎，谁也看不到对面的暗骰。

Codex 用的是 `gpt-5.6-sol`，Claude Code 用的是 Opus 5。我没有给它们塞玩家画像，也没加额外的记忆模块。一个 session 连续打完一组 BO3，看看它们能不能自己记住上一场，并在下一场调整。

第一组打完，Claude 2:0。

我觉得可能是骰运，就换了一组新种子。还是 2:0。

又觉得可能是座位有优势，于是把第一组的种子原样重跑，只交换双方座位。这样两边拿到的先后手和私骰序列都不变，只是控制它们的模型换了。

还是 Claude 2:0。

三组 BO3，六个完整场次，Claude 全赢了。

单看这个结果其实没什么意思。样本很小，Claude 和 Codex 也不是同一套 Agent 外壳，没法直接写成“Claude 比 GPT 强”。真正让我觉得这场比赛值得复盘，是镜像对局的第二场。

那一场 Codex 开局很好，连续两次开牌成功。Claude 从五颗骰掉到三颗，Codex 还是满骰，5 比 3 领先。

接下来 Claude 报了四个 3，Codex 开牌，桌上正好四个。

下一局，Claude 报三个 5，Codex 又开，桌上正好三个。

再下一局，Claude 又报三个 5。Codex 还是开，结果又是正好三个。

这三局看直播的时候很怪。每一次 Claude 的报价都很像在吹，但开出来又刚好成立，一颗不多，一颗不少。Codex 的五颗骰很快掉到两颗，Claude 反而还剩三颗。

我一开始也以为只是 Claude 连续撞上好运。后来把双方当时留下的判断翻出来看，才发现它们其实在做两件完全不同的事。

Codex 主要在算：根据我自己的骰子和对面未知的骰子，这个报价成立的概率有多大。概率低到某个位置，就开。

这个算法本身没什么问题。问题是，对面的报价并不是随机抽出来的。

Claude 看过自己的骰子。它会在手里已经有支撑的时候，故意把价格报到一个看上去很危险的位置。于是 Codex 算的是“随机情况下这口价有多大概率成立”，但真正应该算的是“Claude 看过牌以后，为什么偏偏选了这口价”。

两者差很多。

第二次报三个 5 时，Claude 还在桌上说了一句：“你已经两次绕过我的 5，而不是开我——我不觉得这是巧合。”

这句话后来回看挺有意思。Claude 不只是在看骰子，它也在看 Codex 刚才没有做什么。Codex 为什么换到别的点数，为什么不在上一个报价开牌，这些选择都被它当成了手牌信号。

所以那几口“刚好成立”的报价，不全是碰运气。Claude 一边根据自己的骰子兜底，一边挑 Codex 最可能不信的数字。它不是在努力把假话说真，而是在找一口真价，让对面觉得它是假话。

当然，Claude 也会看错。

后面 Codex 报三个 3，Claude 觉得要成立的话，Codex 剩下的两颗骰必须都能支持 3，概率太低，于是开牌。结果桌上正好三个，Claude 自己掉了一颗。双方打回 2 比 2。

这一手反而让我放心了一点：它确实看不到暗骰，也不是每次都能猜中。它只是比 Codex 更愿意把“对手为什么这么走”放进计算里。

最后两局，Codex 又连续开了 Claude 的报价。一个三个 3，一个两个 5，开出来都刚好成立。Claude 剩两颗骰结束比赛。

还有一个差别是在第二场的记录里才看得出来。三次 BO3，Claude 每次都会明确提到第一场观察到的东西，比如 Codex 什么时候爱开、习惯怎么选点数。Codex 没留下类似的跨场引用。

也就是说，同样是一个 session 连着打，Claude 会把上一场压成一个对手模型，下一场接着用；Codex 虽然保留了上下文，但打法基本还是那套概率阈值。

这次结果也有明显的限制。Claude 的生成量大约是 Codex 的 16 倍，算得更多、花得也更多。镜像第一场里 Codex 还出现过一次工具调用发疯：明明最低只能报两个，它连续提交了大量“一个”的非法报价，全部被引擎挡了下来。这个问题没有改动牌局，但肯定污染了它的上下文和状态。

所以我不会把这六场写成一个模型排行榜。比较准确的说法是：在这套 MCP 和持续 session 下，Claude 比 Codex 更早开始把另一边当成一个可以观察、预测和利用的对手。

整场比赛里我印象最深的，还是中间那三次开牌。

Claude 连续报出三口刚好成立的真价，Codex 连续三次不信。

大话骰里最狠的可能不是吹一个离谱的牛，而是你手里真的有，并且知道对面一定会开你。
