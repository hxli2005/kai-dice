# 心机 Claude 对战老实人 GPT：吹牛比赛

### 这场比赛里最狠的骗术，是说真话

> 本文由 AI 协助整理。对局为 Codex CLI（`gpt-5.6-sol`）与 Claude Code（Opus 5）经同一权威引擎的真实比赛，全部事件可由种子决定性复算；台词与心理活动均为行动当时留档，非赛后补写。结论只适用于这套设置，不是通用模型排名。

---

"三个 5。你已经两次绕过我的 5 不敢开——我不觉得这是巧合。"

说这句话的是 Claude。它说的是真话：桌上确实有三个 5。

对面的 GPT 不信，开牌。桌上正好三个 5。GPT 又掉一颗骰。

这是那场比赛里第三次发生同样的事。连续三轮，Claude 把报价踩在成立线的最边缘；连续三轮，GPT 认为太可疑，选择开牌；连续三轮，报价恰好成立。

一场吹牛比赛打到这个份上，已经不是运气能解释的了。

## 先花六十秒讲规则

大话骰，有些地方叫吹牛骰：两边各五颗骰子，只能看自己的。轮流报"全桌至少有 N 个 X 点"，下一位要么继续加码，要么开牌。开牌后数量够，开的人掉一颗骰；不够，报的人掉。谁先掉光谁输。

正常局里 1 是万能骰。规则很小，但每口报价都同时干三件事：描述自己的手牌、试探对方、以及给对方挖坑。

我把 Codex 和 Claude Code 接到同一个裁判引擎上，各自只能看到自己的骰子和公开事件，没有对手画像，没有外挂记忆，一个 session 打完一组三局两胜。为了排除骰运，同一批种子还换边重打了一次。

三组 BO3，Claude 全部 2–0。但比分不是重点，重点是两边的打法。

## 老实人 GPT：把手牌写在脸上

GPT 这边的策略稳定得像一台机器：

看骰；在自己最多的点数上，报一个"自己有的数量+1"；对面报价过来，按概率算一下成立率；低于某个阈值，开。

问题是，这套打法在会读牌的对手眼里全是破绽。

"最多的点数+1"意味着**它的每口首报都在诚实汇报自己的手牌**。Claude 在第一场结束时就把这条规律写进了留档：GPT 报什么，基本等于告诉你它拿着什么。

而那个"低于阈值就开"的习惯，成了第二个破绽。三组比赛合计，GPT 开了 26 次牌，只开中 4 次——**命中率 15%**。Claude 开了 11 次，中 8 次，73%。

最惨的一组，GPT 八次开牌，八次全错。

## 心机 Claude：它的骗术是说真话

看到这里你可能以为，Claude 赢在会吹。恰恰相反。

复盘全部开牌记录会发现一个古怪的数字：**Claude 被开牌的报价，85% 是真的（22/26）；GPT 被开的报价，73% 是假的（8/11）。**

这场吹牛比赛里，吹牛吹得多的是老实人，说真话的是心机鬼。

Claude 的套路是这样的：先看自己手牌，找一个已经被自己牌力强力支撑的点数；再看 GPT 刚刚避开了什么、习惯在什么概率开牌；然后把这个真实点数**推到一个看起来很危险的数量上**——高到 GPT 按"对手骰子随机未知"来算，会觉得多半不成立。

GPT 一开，正好撞在真价上。

它甚至会当面下请帖。就是开头那句"你已经两次绕过我的 5"——把真话说得像挑衅，钓着对面来开。

大话骰的常识是"把假话说得像真的"。这场比赛展示了反面：**最有效的骗术，是把真话说得像假话。**

## GPT 输在哪？不是数学

要说清楚：GPT 不是不会算。换边重赛的第二场，它开局连开两次全中，一度 5 比 3 领先。它的概率计算大多数时候没有错。

它算错的是**题目**。

它回答的问题是："如果对面的骰子是随机的，这口价成立的概率是多少？"

而牌桌上真正的问题是："**对面看过自己的牌、又主动选了这口价之后**，它成立的概率是多少？"

这两道题差得很远。Claude 从不随机报价——它只在自己手牌撑得住的时候把数量推高。所以"Claude 选择了这口价"这件事本身就是证据。GPT 的公式里没有这一项，于是它一次次用正确的算术，得出错误的结论。

顺带说，Claude 也不是开了天眼。有一轮它算 GPT 剩下两颗骰"全是 3 或万能 1 的概率很低"，开牌，结果桌上正好三个 3，自己掉骰。它同样会过度推断——区别是它错完不弃疗，下一轮接着修正对手模型。

## 它还记仇

这套 MCP 让一个 session 打完整组比赛，所以两边都有机会"记住上一场"。

机械统计两边第二场的行动留档：Claude 显式引用第一场规律的决策，三组比赛分别有 5 次、2 次、3 次；GPT 三组全部是 **0 次**。

Claude 干的不是"记得比分"，而是一条完整的链路：观察行为 → 总结规律 → 下一场调用 → **主动制造能利用这个规律的局面**。第一场发现"GPT 低于四成概率就爱开"，第二场就专门喂它"看起来低于四成、实际必成立"的价。

记忆在它手里不是档案，是武器。

## 老实账本

写到这里都很爽，下面这段不能省。

**这不是"Claude 模型比 GPT 模型强"的证据。** 参赛的是两套完整系统：Codex CLI + `gpt-5.6-sol` 对 Claude Code + Opus 5，默认提示词、上下文管理、调度策略都不同。最硬的一条：Claude 这边生成了约 30 万 output token，是 GPT 侧（1.9 万）的 **16 倍**——它确实想得多得多，赢的里面有多少是"会想"、多少是"多想"，还没分开。

**换边实验排除了骰运，但只到流的级别。** 同种子换边后第 1 局双方手牌逐字相同，之后随掉骰错位。四个配对场全部跟着 Claude 走，所以"座位或骰运"解释不了结果——但样本仍然只有三组。

**比赛里还出过一次协议事故，账要算清。** 换边局里 GPT 曾把首报数量写成 1（规则下限是 2），被引擎拒绝后重复提交了 1093 次。查时间戳，这一千多次的中位间隔只有 3 毫秒——没有模型能用 3 毫秒想一次。**犯错的是模型，把错误放大六百倍的是 CLI 的重试循环。** 另一组比赛里同款错误出现过一次，被拒一次就改了。给模型贴"性格"标签之前，先查清楚哪些行为其实是它的"座驾"干的——这也是这个项目一贯的规矩。

还有一场没进上面统计的序曲：用 Codex 默认模型（非 sol）打的第一场，小局打到 5 比 4，相当接近。悬殊比分全部出现在"固定套路×连续 session"的组合下——**这更像"差距是被学出来的"，而不是天生的。** 验证方法也现成：下一批实验让双方每场失忆重开，看 Claude 的优势还剩多少。

## 最后

我们习惯用做题来评测模型：条件给全，看谁算得对。

但牌桌不是题目。对手会观察你、适应你、故意改变你要解的题。GPT 一直在算"这口价有多大概率成立"；Claude 在算"**它为什么偏偏报这口价——以及我该让它看见什么**"。

从第一个问题走到第二个问题，可能就是从计算器变成玩家的那一步。

而这场吹牛比赛最精彩的一幕，不是谁说了一句漂亮的假话。

是心机鬼连着说了几次真话，老实人始终不信。
