## 1. 概率表盘怎么算

### 1.1 函数

```
probBidTrue(bid, myDice, oppCount, zhai) → [0, 1]
```

回答一个问题：**"桌上至少有 count 个 face"这句话为真的概率**——从"我"的视角。

### 1.2 数学

三步：

1. **已见匹配数**：在自己骰面里数 `face`（飞局把 1 也算上）。
   `mine = countBid(bid, myDice, zhai)`
2. **还缺几个**：`need = bid.count − mine`。`need ≤ 0` 直接返回 1（这话已然为真）；`need > 对方骰数` 返回 0（物理不可能）。
3. **对方未知骰补齐的概率**：对方 `oppCount` 颗骰视为均匀随机，每颗命中概率
   - 飞局且报点 ≠ 1：`p = 2/6`（本点 + 癞子 1）
   - 斋局，或报点 = 1：`p = 1/6`

   则 `P = P(X ≥ need)`，`X ~ Binomial(oppCount, p)`，二项分布尾部精确求和（无近似、无采样）。

例：我 5 骰 `[3,3,4,4,6]`，对方报「3 个 4」（飞局）。已见 4,4 共 2 个，缺 1；对方 5 颗每颗 1/3 命中，`P(X≥1) = 1 − (2/3)⁵ ≈ 87%`。

### 1.3 视角与两个前提假设（重要）

**是的，纯单方视角**，且带一个明确的行为假设：

| 前提 | 含义 |
|---|---|
| **信息 = 自己骰面 + 对方骰子数量** | 不含对方任何私有信息。架构上也拿不到：`observe()` 返回的 schema 里根本没有对方骰面字段（§4）。 |
| **对方骰面 = 均匀随机**（"乱报假设"） | 不利用对方的报数历史做贝叶斯更新。对方报「3 个 4」这件事本身其实是证据（诚实玩家报 4 说明他手里多半有 4），表盘刻意不用这个证据。 |

第二条是**设计决定而非缺陷**（附 B.1 原文）：*"表盘是地板不是答案：它假设对面乱报，而游戏建立在对面不乱报上——AI 可以剥削'表盘奴隶'（贴着你的开牌阈值上方虚报），你的计算器会成为它的鱼饵。"* 读心的空间就在真实概率与表盘数字的差值里。

### 1.4 双发（附 B.1 红线）与算盘制（Q45）

同一个函数所有人共用；**准数要付代价**——不是藏答案，是给答案标价，价＝公开性：

| 使用方 | 什么时候有准数 | 呈现 |
|---|---|---|
| 玩家 | 拨过算盘的那一局（`#gauge`） | 「3 个 4」真 87%（只算骰面 · 不算人）；没拨＝桌面零显示 |
| 玩家（新手训练轮） | 首 3 场自动给 | 粗档：基本稳／五五开／悬／纯扯 |
| AI（LLM） | 本局 `calc` 过 | prompt 给精确 P；没算只给同一套粗档词 |
| 沉默模式 bot | 永远（豁免） | 内部阈值行棋，但嘴里只有粗档（`voice.js`） |

- `calc` 是**引擎动作**：轮到你、每局一次，落一条公开事件 `{type:'calc',player}`——**动作公开、结果私有**（结果各自客户端用自己的骰子算，引擎不发数）。
- 何时算＝新的 tell，进 `narrate()` 喂给全桌 AI；人设算频写在 `gear.calc`（老李头 often／先生 key／阿飞 never＝身份锚点，不给候选）。
- **引用校验**：没算过就说出准数（"三成""87%"）＝编数字，`hasFakePrecision()` 当场掐掉 say/note；发给它的档案数字照引不误。

## 2. AI 提示词管线

### 2.1 调用预算与形态

DESIGN §3.1 限定**每手 1 次调用 + 结算 1 次**（成本 <0.5 元/场）。没有做多轮 function calling——事实随 prompt 注入（附 B.1"事实工具可有"；注入的全部是事实，没有"该怎么做"的建议，策略红线未破）。

Q45 之后精确概率不再无条件注入：想要准数，它得先花一手拍 `calc`（keepTurn），所以**"算手"＝两次调用**——算频高的人设（老李头）单场调用量上浮，配额口径见 SYNC。

### 2.2 SYSTEM（由人设五件套拼装，Q10）

人设是一等公民对象（`personas.js`：身份/嘴臭度/策略倾向/回复风格/装备），SYSTEM 全部从对象拼出：

```
你是{name}，{identity}正和客人玩大话骰。{TONES[tone]}{style}你收到的全是真实数据，禁止编造数字。
{flaws ——Q11 性格缺陷：要面子（嘴棋耦合）/记仇/自负，可被玩家读出利用}
规则提要：（同前）
严格输出一行 JSON：{"action":…,"say":"台词","note":"决策理由"}
```

花名册：**老李头**（tone=hell；常算、稳健记仇、不用盲）、**阿飞**（spicy；从不碰算盘、爱盲、秒出）、**先生**（cold；关键手才算、用斋不用盲）、**客席**（素颜模型，无性格剧本，规矩一件不少）。嘴臭度绑定人设、无玩家设置项；Q6 内容边界（只锚定真实数据、只毒打法、不碰人身、不用脏话）为全人设不变量。

### 2.3 USER（每手动态拼装，五段事实）

`buildPrompts(ob, profile)` 按固定顺序拼五段，**全部来自引擎 observe() 与本地档案，无一编造**：

| 段 | 内容 | 来源 |
|---|---|---|
| ① 局面 | 第几局、自己骰面、对方骰数、池深、斋标记 | `ob.yourDice / diceCount / potUnits / zhai` |
| ② 本局进程 | 看骰/报数/宣言/**拨算盘**的时序叙事；用时只在极端时化成现象学一句（Q15：不报秒数） | 公开事件流 `narrate()`；揭盅与拨算盘的时机都是阅读材料 |
| ③ 当前报价 | 报价内容 + 为真概率：**算过给准数，没算给粗档词**（Q45） | `probBidTrue` / `coarseWord` |
| ④ 可选动作 | 开牌；抬价候选=P 最高的 6 个（粒度同上）；可用宣言；**拨算盘**（算频非 never 时）；词条动作 | `allLegalBids` × `probBidTrue` |
| ⑤ 档案 | 跨场摘要（场次胜负、上场虚报率/开牌命中/平均思考）+ 他的旧笔记末 5 条 | localStorage `profileBrief()`，与玩家在"它眼中的你"页看到的是**同一份**（§5.1 明牌） |

### 2.4 样例（Q45 口径：同一局面，算与不算两副面孔）

玩家先看骰、停了很久才报「3 个 4」，轮到老李头——**他还没拨算盘**：

```
第 1 局。你 5 颗骰：[3, 3, 4, 4, 6]，对方 5 颗暗骰。池 2 注。
本局进程：对方掀盅看了骰；对方报 3 个 4（这手前停了很久）。
当前报价：对方报「3 个 4」。你没拨算盘，只有手感：这话基本稳。
可选动作：开牌；抬价（候选：3个6=基本稳，4个3=基本稳……）；当众拨算盘
（{"type":"calc"}）——算完这一局你都有准数，算盘拨在明处：全桌都看得见你在算。
你习惯算：多数手你会当众把算盘拨一下——但数是数、人是人，你照样可能逆着数开。
```

他拍了 `calc`（这一拍全桌可见，也进了对手的叙事），下一次调用才拿到准数：

```
当前报价：对方报「3 个 4」。你这局拨过算盘：按你的骰子算，此话为真的概率 87%
（只算骰面，不算人——他是不是在诈，算盘不管）。
```

### 2.5 输出解析与降级链

`parseDecision(text, ob)`：

1. 从回复中提取首个 `{...}` 块，`JSON.parse`；
2. **合法性校验**：动作类型必须在 `ob.legal` 集内；bid 还要过 `isLegalBid` 阶梯校验（数量/点数/上限）；
3. `say` 截 60 字、`note` 截 120 字；
4. 任何一步失败 → 返回 `null` → **降级沉默模式**（SilentBot 顶班落子，无台词），事件记 `silentFallback: true`。

LLM 网络层（`llm.js`）：双格式（OpenAI 兼容 / Anthropic），key 只存 localStorage、默认 10s 超时。通道分流（Q28）：官方人设走暗号→同域代理（设备日配额＋全局月熔断），客席走自带钥匙直连。降级链：通道 → 沉默模式（＋F2 的事实模板台词）。

**决策日志**（附 B.3）：每手记 `{round, facts(注入的全文), raw(LLM 原始回复), action, say, note, silentFallback}`——这是"台词不许编"的审计落点，note 结算后进档案。

### 2.6 结算判词（第二类调用）与沉默模式

- `settleVerdict(channel, {won, statsText})`：场终 1 次调用。SYSTEM 复用人设（去掉动作 JSON 约束，换成判词约束），USER = 本场统计文本（局数胜负、虚报率、开牌命中、被开、最久一手想了几秒报了什么）。输出 `{verdict(给客人的判词), note(记档案)}`，失败降级模板判词——模板同样只用真实统计填充。
- **沉默模式**（`silent.js`）：无 LLM 时的纯数学行棋。规则仅两条：对方报价 `P <` 阈值（人设参数，老李头 0.25）或无价可抬 → 开牌；否则报**自己视角 P 最高**的合法抬价。不宣言、不拨算盘、不用词条（扣扳机必须是模型，Q22-补）。
- **沉默模式的"被读"底线**（F2／`voice.js`）：它开牌时仍要说出为什么——粗档 + 一句本局真事实（"你骰都没看就压我""你算完才敢报这个数""都第 5 手了"），按人设声口拼（`persona.voice`）。纯模板、零模型、零编造、零准数：降级可以降嘴皮，不许降掉唯一的差异化。

### 2.8 场合律：系统说话零容忍，他说话零审查（Q49，替代 Q46/Q47 的全局管制）

分场合，不分语气：

| 场合 | 谁在说 | 规矩 |
|---|---|---|
| **系统栏位**：结算数字、报告卡数据面、档案客观层、表盘、规则事件 | 引擎渲染（`computeStats` 从事件流复算，模型碰不到） | **错即 bug**。回归见 `test/factcheck.test.js`「系统场合零容忍」 |
| **他的场合**：台词、判词的意见话、小本子右栏 | 模型 | **零审查**。误判、过度自信、言行不一、记仇、把旧账记歪——全放行，那是野生对手的活性 |

三锁不放：信息边界（§4 schema 隔离）、动作合法性（引擎结算）、**真迹不可赛后重写**（禁事后供词）。

- **事实纪律降格为人设装备**：先生从不错账（可怕的精确）／老李头会记歪且嘴硬（真歪装歪永不可知）／阿飞记性稀烂还理直气壮——写在 `flaws` 里，不再是全局法。
- **留档不是审查**：`belief`（真实判断）＋`speechMode`（`bait`＝有意误导）＋`reaction`（被戳后 hold/fold/ignore）仍然每手落决策日志——它们是复盘室（F8）右轨、揭诈（F7）与嘴硬率（F9）的素材，**不再是合法性判据**。
- **「戳他」（F9）**：解链的安全阀。三枚短语（你记错了／你在演／慢着）零打字塞进他的下一手提示词；他嘴硬、改口还是装没听见，自己在 `reaction` 里交底，进档案的嘴硬率与小本子右栏。
- `factcheck.js` 留任：从"拦他的嘴"改任"守系统栏位＋当观测尺子"（读心门禁里数一数他嘴上把旧事说歪几次，只报数不判罚）。
- **蒙报类目**（F0c，保留）：没看骰就报的价单列统计，虚报率只算"看过骰之后报的那些口"——否则故意闭眼报到天上的人会被**档案**写成"老实人"（那是系统栏位，属零容忍区）。宣言盲＝盲侠，事实上没看骰＝蒙眼虎。
- **读心回归**（F0d，附 B.2 新增一关）：同一局面换玩家画像，开牌分布必须跟着动（不动＝档案是摆设）。`npm run readgate`（需 `KAI_KEY`）跑真通道；无通道记"未测"。

### 2.7 公平性小结

- 他**拿不到**你的骰面——不是承诺，是 `observe()` schema 里没有这个字段；
- 他算概率用的函数和你算盘上的**同一个**，而且**要准数就得当众拨算盘**，和你同一条规矩（Q45）；
- prompt 里没有任何策略建议（没有"建议开牌"、没有最优动作表），只有世界的事实——他怎么打，是模型自己的事。
