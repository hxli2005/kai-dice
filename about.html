开！

大话骰。对面坐着会算、会记仇、开你之前把推理念出来的对手。

玩法

  • 每人五颗暗骰，各自摇各自的。轮流报数：「桌上（全桌合计）至少有 N 个 X 点」。
  • 报数只能往上抬：数量加大，或数量不变、点数加大。首报至少 2 个。
  • 1 点是万能牌，替任何点数凑数。宣过「斋」的那一局除外。
  • 不信就拍「开」——三人桌上只能开你上家（上一个报价的人）。清点全桌：数够了，开的人输；不够，报的人输。
  • 输家掉一颗骰子。骰子掉光出局旁观，打到只剩一人。
  • 注池：每局全桌各押 1 注底；每报一次数，全桌各自动加 1 注。开牌局胜者收整池——看客的注也在池里。
  • 筹码面额：白 1 · 红 5 · 绿 25 · 黑 100（金环）。身家跨场连续，输光了赊账继续打，也可随时「翻篇」清账——但翻篇会被记进档案。
  • 桌上人人是独立玩家，各揣各的家底——他们的比你厚。你的每一枚筹码都得从他们手里赢；大厅的榜挂着全馆座次，点谁的行看谁的底。
  • 不限时。你手停多久，他们看得见，也记得住。

宣言

  • 盲：整局不看自己的骰子，本局池 ×2。只要还没看骰就能宣——报过数也行，算追认裸报。
  • 斋：本局 1 点不作万能，池 ×1.5。只有一局的首报者能宣。
  • 抬：轮到你时拍章，本局池 ×2。每人每局一次，全桌对等生效——空手抬也是合法演技，抬的时机自己会说话。
  • 报价抬到第 6 手起进深水：池自动再 ×2。全部倍率相乘。

表盘

屏幕上的概率只按你手里的骰子和纯运气算，不猜人心。对面敢不敢这么报、是不是在钓你开——得你自己读。他们那边的表盘和你的是同一个算法。

为什么信它

  • 每局开始，各家骰面连同随机数封成哈希先上屏（菜单「封印」可查全文）；摊牌时开封可验——谁都不能重掷。
  • AI 和你走同一套接口、拿同构的字节：接口里没有你的骰面这个字段。公平由架构保证，不靠承诺。
  • 你落子之前的犹豫、悬停，一概不采样。
  • 系统说话零容忍，他说话零审查。 结算、报告卡的数据、档案统计、算盘——这些由引擎从事件流复算，一个字错了都是 bug。至于他的嘴：他可能误判、可能夸大、可能把上回的账记歪。那不是故障，那是对手。觉得他记错了，桌上有「戳」——当面戳回去，看他嘴硬还是改口。

桌上的机器：型号与机位

  • 模型是真身。 坐在对面做决定的是一个语言模型。它算不算、什么时候掀盅、要不要开你这口价，全是它自己的判断。
  • 机位是座位。 一号机、二号机、三号机——那是一个机号、一枚名章，外加一条明牌的座位规则（一号机桌上常有算盘但扳不动盲闸；二号机根本没有算盘，可它能不看骰就宣盲；三号机关键手才有算盘，而且它钉的是另一个型号）。机位没有性格——我们一个字都没给它写过。它们之间的差别只有两处：桌上有没有那个工具，钉的是哪个型号。
  • 提示词只管规则。 发给它的提示词里只有三样：大话骰的规则、它能做哪些动作与输出格式、这一局实际发生了什么。没有性格剧本，没有嘴臭度，也没有任何一句"你该怎么说话"的交代——连"用你自己的判断"这种话都没有，因为那本身就是在规定它该是谁。 怎么打、怎么说、说什么，全是它自己的判断，所以换一个型号，你换到的是另一个对手。
  • 它的嘴我们不管。 我们不向模型下发任何内容约束，也不在出口做过滤——台词的边界就是那个模型自己的边界。你用自己的钥匙接一个没做过对齐的本地模型，那它说什么都归你自己负责。
  • 各记各的账。 档案、身家、榜上那一行，按模型名分开。同一个模型，走托管还是走你自己的钥匙，都是同一个人。

开局前选桌：单挑一人，或三人同桌，对手自选。选桌页上就写着他们各自对你的战绩。

接入

  • 什么都不用配（默认）：大厅第一席就是托管模型，直接开局——这一席的账由我们出。每天有一份免费额度，用完了明天再来。
  • 拿到暗号的：大厅「设置」里填暗号，解锁全部机位与更高的额度。机位只走官方通道：谁来打，接的都是同一个型号。
  • 自带 API 的：大厅的「客席」卡上填 Base URL / API Key / Model——你的模型以本名入座，规矩与托管席一模一样。兼容 OpenAI 格式与 Anthropic 格式；填 OpenRouter 的地址还能当场拉一份现在的模型清单挑（一把钥匙开一屋子模型）。钥匙只存这台设备，浏览器直连模型商，不经任何中间服务器。
  • 什么都不填：人都在，只是不说话——按数学行棋。开牌那一拍他仍会告诉你为什么。
